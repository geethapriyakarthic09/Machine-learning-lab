# Ex 05 - K-Nearest Neighbours Classification (Iris)

**Aim:** Classify the Iris dataset using KNN (k = 6) and print both correct and wrong predictions.

**Steps:** import libraries -> load Iris -> split 80/20 -> train KNeighborsClassifier -> predict -> classification report + confusion matrix.

**Run:** `pip install -r requirements.txt` then `python knn_iris.py`

**Files:** `output.txt` (real program output), `confusion_matrix.png`

Note: `random_state=42` is added so you get the same result every run (the manual had none, so results changed each time).
