# Ex 01 - Decision Tree Classification (Iris dataset)

**Aim:** Implement a decision tree on a real-world dataset (Iris) and classify a new sample.

**Steps:** load data -> explore -> pair plot -> train/test split (90/10) -> train DecisionTreeClassifier -> evaluate -> confusion matrix -> visualize tree -> predict new sample.

**Run:** `pip install -r requirements.txt` then `python decision_tree.py`

**Files:** `Iris.csv` (dataset), `output.txt` (real program output), `pairplot.png`, `confusion_matrix.png`, `decision_tree.png`

**Result:** new sample [4.8, 2.9, 1.3, 0.2] is predicted as Iris-setosa.
